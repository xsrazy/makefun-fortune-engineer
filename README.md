## The fortune

> You will rename a variable and break three services you did not know existed.

A single one-line fortune cookie message for a software engineer (77 characters, under the 120-character limit). Classic cookie opening, twist from the engineer's own world, funniest word at the end.

## How it works

`main.py` writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). It validates the line first: exactly one line, non-blank, at most 120 characters.

```sh
python3 main.py
cat /output/entry.txt
```
